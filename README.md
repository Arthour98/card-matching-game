# Card-Match Game

A memory matching card game built with vanilla JavaScript. Test your memory by finding matching pairs of playing cards!

## Game Overview

Card-Match is an interactive web-based memory game where players flip cards to find matching pairs. The game features 20 cards representing 5 different playing card types, with each type appearing 4 times.

## Features

- **Memory Challenge**: Flip cards to find all matching pairs
- **Flip Counter**: Track how many flips you've made throughout the game
- **Randomized Deck**: Cards are shuffled randomly each game for variety
- **Win Detection**: Automatic detection when all cards are matched
- **Replay Function**: Play multiple rounds without refreshing the page
- **Responsive Design**: Works on different screen sizes

## Card Types

The game uses 5 playing card types:
- Asos (Aces)
- Dama (Queens)
- Jack
- King
- Jocker (Jokers)

Each card type appears 4 times in the deck for a total of 20 cards.

## How to Play

1. Open `index.html` in your web browser
2. Cards will be revealed briefly at the start, then hidden
3. Click on cards to flip them over
4. Try to find matching pairs
5. When you flip a matching pair, they stay revealed
6. When a mismatch occurs, cards flip back after 0.5 seconds
7. The flip counter increases with each card flip
8. Continue until all pairs are matched
9. Click the **Replay** button to play again

## Challenge

Try to match all pairs with the fewest flips possible! The game includes a humorous message if you exceed 30 flips.
